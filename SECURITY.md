# Security Policy

Supported release: `0.1.3.3`.

## Reporting a vulnerability

Please use GitHub Private Vulnerability Reporting for this repository (Security → Advisories → Report a vulnerability).

Do not place secrets, credentials, personal data, or live exploit material in public issues. Report the affected version, platform, minimal reproduction, and whether verification correctness, archive safety, or package identity is affected.

ProofForge is limited to authorized research and evidence handling.
